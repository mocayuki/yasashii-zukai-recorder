# 公開版について

このリポジトリは、やさしい図解レコーダーの実装を紹介するために公開したソースコードです。

## 含まれるもの

- macOSアプリの画面、収録、編集、文字起こし、字幕、動画書き出し、投稿管理。
- Cloudflare Workers上の投稿ハブとSNS連携。
- 共通の型・処理、既存のユニットテスト、仕様書、ビルド設定。
- 過去のブラウザー版の参照用アーカイブ。

## 公開用に整理したもの

- READMEと画面画像を追加・整理。
- 投稿ハブの公開URL・データベースID・サイト所有確認値を雛形に変更。
- ローカル設定・認証情報・ユーザーデータの除外ルールを補足。

元のアプリの開発履歴を移したものではありません。公開後の変更履歴はこのリポジトリに残ります。

アプリの機能と設計を確認するための公開版です。各SNSへの実際の接続・投稿には、ご自身のアカウントと設定が必要です。
